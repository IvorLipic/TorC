How TorC's autograd actually works

TorC is a from-scratch C++ tensor library. These animations were generated from real runs of the library: every number and every edge below comes from the program's own output, and every gradient is cross-checked against finite differences.

The idea in four sentences

Each operation (torc::mul, torc::add, …) computes its result immediately and attaches a TapeEntry to the output Variable: raw pointers to its inputs and a closure that maps the incoming gradient to a gradient per input. backward() topologically sorts the graph from the root, seeds it with 1, and runs the closures in reverse order. Each closure's result is added into every input's grad, so a variable that is used several times gets the sum of its contributions. Broadcasting is undone in one place, by summing the gradient down to the input's shape.

1 · One variable, several uses

y = x*x + x at x = 3. Math: dy/dx = 2x + 1 = 7. x is an input of mul twice and of add once, so three contributions (3 + 3 + 1) are accumulated into x.grad.

Variable x(Tensor({3.0f}, {1}), true);
Variable m = mul(x, x);
Variable y = add(m, x);
y.backward();          // x.grad() == 7

2 · The chain rule, and a gradient that stops

f = sum(relu(a*b + c)). Each node multiplies the incoming gradient by its local derivative: sum passes 1 to every element, relu passes it where its input was positive and blocks it otherwise, add copies, and mul swaps the factors (da = g·b, db = g·a). The third element has a*b+c = −2 < 0, so everything upstream of it gets 0.

Variable ab = mul(a, b);
Variable z  = add(ab, c);
Variable r  = relu(z);
Variable f  = sum(r);
f.backward();

3 · A tiny network

L = mse(relu(x@W1 + b1)@W2 + b2, t) with a batch of one. The bias b1 (shape {2}) is broadcast over the batch in add; backward_with_grad sums the gradient back down to {2} (reduce_sum_to_shape). The second hidden unit is negative before ReLU, so W1's second column, b1[1] and W2[1] all receive zero gradient. It is written with explicit ops so each intermediate is visible; nn::Linear computes the same thing but keeps its intermediates private.
