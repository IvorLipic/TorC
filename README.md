# TorC Learn

Interactive learning material for **[TorC](https://github.com/IvorLipic/TorC)**, a from-scratch C++ tensor and autograd library.
Live site: **https://ivorlipic.github.io/TorC/**

This branch (`web`) is a separate project from the library on `main`: it contains no library source. Every number on the
site comes from a real run of TorC, built from a pinned release (see [docs/architecture.md](docs/architecture.md)).

## What is here

| Path | What |
|---|---|
| `site/` | The static website (plain HTML/CSS/JS, KaTeX vendored). Deployed as-is to GitHub Pages. |
| `site/engine.js`, `explain.js`, `scenes.js`, `app.js` | JS port of the autograd rules, "paper work" generator, lesson layouts/text, UI. |
| `site/data/` | JSON written by the C++ trace programs (committed, regenerated by `tools/trace/run.sh`). |
| `site/test/` | Node tests: JS engine == real C++ output, finite differences, every LaTeX string parses. |
| `tools/trace/` | C++ programs that run the real TorC (fetched at the version in `tools/trace/TORC_REF`) and emit JSON. |
| `docs/` | Architecture, content plan, lesson-authoring guide, decisions, notes from auditing the library. |
| `ROADMAP.md` | The plan and status for this project. |

## Run it

```bash
python3 -m http.server -d site 8000        # open http://localhost:8000/   (fetch() needs HTTP, not file://)
node --test site/test/                     # Node >= 20: engine vs. real library output, LaTeX validity
tools/trace/run.sh                         # regenerate site/data/*.json from the pinned TorC (clang >= 18 or GCC >= 14, CMake >= 3.24)
tools/trace/run.sh --check                 # fail if the committed JSON is stale (also run in CI)
```

Current lesson: **Backprop lab** — step through forward and backward passes, see the rule and the same rule with real numbers
at every node, and edit the inputs to watch gradients respond. More lessons are planned; see [ROADMAP.md](ROADMAP.md).

## Contributing / working agreements

See [CLAUDE.md](CLAUDE.md) (also the guide for AI agents working on this branch) and [docs/authoring.md](docs/authoring.md).
Short version: numbers are never typed into lessons by hand; changes are verified by tests and an independent review before they
reach `web`'s deployed site; library bugs are reported and fixed on `main`, not worked around here.
